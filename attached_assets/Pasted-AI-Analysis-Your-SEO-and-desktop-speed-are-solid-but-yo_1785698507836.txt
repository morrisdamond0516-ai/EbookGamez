AI Agents
Fix next
FAQPage structured data

No FAQPage schema found. AI assistants use FAQ markup to surface your answers directly in their responses.

What to do

Add FAQPage JSON-LD to pages that answer common questions. This helps ChatGPT, Perplexity, and Google AI Mode quote your content when users ask related questions.

Paste as a <script> tag on any page with FAQs

Copy
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "What is your return policy?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "We accept returns within 30 days of purchase for a full refund."
      }
    },
    {
      "@type": "Question",
      "name": "How long does shipping take?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "Standard shipping takes 3–5 business days. Express is 1–2 days."
      }
    }
  ]
}
</script>

Security
Fix next
Quick fix · ~5–15 min
X-Content-Type-Options

X-Content-Type-Options header missing.

What to do

Add the header: X-Content-Type-Options: nosniff. This prevents browsers from guessing a file's type, blocking a class of script injection attacks. Easy to add in Cloudflare or your server config.

Add to your .htaccess (Apache / WordPress)

Copy
<IfModule mod_headers.c>
  Header always set X-Content-Type-Options "nosniff"
</IfModule>

Security
Fix next
Quick fix · ~5–15 min
Clickjacking protection

No X-Frame-Options or CSP frame-ancestors directive found. Your site could be embedded in another page to trick visitors into clicking things.

What to do

Add X-Frame-Options: SAMEORIGIN or include frame-ancestors 'self' in your Content-Security-Policy. Most CDNs and web hosts allow adding custom response headers.

Add to your .htaccess (Apache / WordPress)

Copy
<IfModule mod_headers.c>
  Header always set X-Frame-Options "SAMEORIGIN"
</IfModule>
